# E-Commerce Furniture Online Store

**Fully responsive E-Commerce furniture online store with a landing page.**

## Landing Page Includes:
- **Multiple sections with scroll-in effect** done using the **Intersection Observer API**.
- **Section featuring conditional rendering**.
- **Section with a slider**.

## Website Features:
- **Client-side filtering** of products by name, company, category, price, shipping, and more.
- **Client-side sorting** of products.
- **Routing** implemented with **React Router**.
- **State management** using **Redux Toolkit**.
- **Responsive design**
